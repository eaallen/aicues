# Make prompt public

If a user wants to make their prompt public, they must:
1. click on a share button to make public
2. if they account does not have a tag, create a tag for themselves
3. confirm they want to make this prompt public

When a prompt is public it should have a world or network icon that is green that to indicatre it is live. if the user hovers over the icon, they can then have the option to make private. if they click on it the prompt becomes private.
